# 💼 Down Work

A modern and responsive job-finding web application built with React.

Down Work helps job seekers discover suitable job opportunities through
category-based browsing, search, filtering, sorting, and detailed job information.

## 📌 About The Project

**Down Work** is a modern job portal designed to make job searching simple,
fast, and convenient.

Users can browse jobs by category, search for specific opportunities,
filter jobs based on salary, job type, work mode, industry, and location,
sort job listings, and view detailed job information.

The project also includes Firebase Authentication, protected routes,
responsive design, loading states, error handling, and a user-friendly interface.
